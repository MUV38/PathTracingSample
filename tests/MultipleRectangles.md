# 複数矩形光源の検証

```powershell
.\tests\RunMultipleRectangles.ps1 -Configuration Debug
.\tests\RunMultipleRectangles.ps1 -Configuration Release
```

構成ごとに逐次実行し、計測中は他の描画テストを実行しません。出力は `build/checks/multiple-rectangles-<構成>/`、`-OutputDirectory` で変更できます。追加の依存ライブラリ・データは不要です。数値テストはWhiteFurnaceTests、画像はDXR対応GPUを使います。

## 数値テスト

既存のテストに加えて2灯／32灯、Lambert／吸収体、2視線角、1候補／RIS／時間相当の2入力／空間相当の5入力の32条件を各131,072サンプルで積分します。矩形の距離に比例して幅と高さを変え、各光源の形態係数を同じにした解析解と比較します。光源色・面積・選択確率を変え、32灯では無効な先頭スロットと黒い2番目のスロットも含めます。

共有HLSLのCDF逆変換、面積PDF、Reservoirのindex保存・復元、法線の異なる入力の統合、候補数制限を通した平均値を解析解に対して `0.0005 + 6標準誤差` 以内とします。最前面交差は前後から検査し、黒い矩形が不透明な遮蔽物になることも確認します。出力は `fixtures/multiple-rectangles.csv` です。この積分は光源ごとに独立した未遮蔽の寄与を足す数値検証で、実シーンの遮蔽は画像で検査します。

## 画像とGPU時間

自作の床・遮蔽物に1/8/32灯の小さな矩形を配置します。暖色・寒色を交互にし、各ライトの放射輝度を64 / 灯数、面積を0.25×0.25 mにして、灯数による総面積×放射輝度の増加を抑えます。配置と色の構成は灯数ごとに異なるため、方式間の比較は同じ灯数の中で行います。

NEE / MIS・RIS・時間・空間再利用について、次の両方を撮影します。

- 固定512サンプル・4 SPP：同じサンプル数での比較。
- GPU処理時間予算：既定500 ms（`-GpuBudgetMs`）に合わせて、4 SPPのフレーム数を調整。

GPUタイムスタンプはReSTIRの準備・再利用・パストレーシングを含みます。`--gpu-budget-ms <100..5000>` でアプリ内の測定時間を累積し、指定時間に達したら撮影します。`--samples` も指定した場合は両方を満たすまで描画します。起動間のクロック変動をフレーム数の事前推定で補う方式は使いません。

CSVは `gpu_ms,samples` 列で、GPU時間は前フレーム、samplesは今回描画した蓄積サンプル数です。GPU平均は先頭10測定フレームを除き、合計は全測定フレームを使います。最後の描画のタイムスタンプは次フレームで読み戻せないため合計には含みません。読み戻しと撮影判定にはフレーム単位の遅延があるため予算を少し超えます。検証は実測合計が予算以上、予算＋最大フレーム時間の2倍＋1 ms以下であることを要求し、実測合計と予算との差もJSONへ記録します。ImGui・Present・CPU時間は予算に含めません。

NEE / MIS・8192サンプル・16 SPPを基準に、PNGを逆sRGB・逆Reinhard変換した線形RGBのRMSEを測ります。自作の黒い同形状モデルによるマスクを使い、右60%以降・下55%以降の物体内部を2画素間隔で検査し、輪郭から2画素を除外します。RGB各平均値は基準画像から±1以内を要求します。`images.json` に要求／実際の蓄積サンプル数・測定フレーム数・GPU平均／合計・RGB平均・RMSE・画素数を保存します。サンプル数は閾値指定なので、撮影フレームの分だけ要求より増える場合があります。

基準も有限サンプルで、8bit量子化と表示変換の逆変換誤差を含みます。乱数列の一部を基準と共有することや、再利用による相関もあるため、これだけで一般的な性能倍率は主張しません。静止画の蓄積を含む比較であり、動くカメラ・動的ライトでの比較は別途必要です。全30枚の保存PNGも開いて確認してください。マウスやキーボードによるUI操作の検証は含みません。

## 操作と制限

ImGuiのRectangle lightsで追加・複製・削除し、Rectangle indexで編集対象を選びます。最後の1スロットはEnable rectangleで無効化します。

CLIでは既存の `--rect-light` と `--rect-*` は選択中のスロットへ作用します。`--add-rect-light` は有効な新規スロットを追加して選択し、`--rect-index <0始まりのindex>` は既存スロットを選択、`--no-rect-light` は選択スロットを無効にします。`--no-rect-mis` は全矩形に適用します。

```powershell
.\build\x64\Release\UsdKitchen\UsdKitchen.exe --rect-light --rect-position -1 2 0 --rect-color 1 0.3 0.1 --add-rect-light --rect-position 1 2 0 --rect-color 0.1 0.3 1 --restir spatial
```

上限は無効なスロットも含めて32です。CDFはCPUで面積×線形輝度から作り、GPUに渡したfloat CDFの差を選択確率に使います。確率0のライトはNEEの対象から外し、BSDFヒットの発光を抑制しません。遮蔽・一次可視・鏡への反射では有効な全矩形から最前面を選びます。交差は線形走査で、ライト用BVHは追加しません。

設定・灯数・CDF・indexは蓄積と履歴の比較対象です。変更時に色の蓄積とReservoir履歴を無効化します。シーンファイルとUSD変換は変更しません。
