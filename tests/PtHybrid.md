# ReSTIR PTの1バウンスhybrid shift

`--restir-pt hybrid` は前フレームの生候補1本を使います。粗さ0.2未満の一次面で選ばれた鏡面またはGGX反射を、保存したBSDF乱数3つから再生します。再生先が元と同じ三角形かつ粗さ0.2以上なら、3番目の平坦なLambert頂点へ再接続します。再接続には表裏と可視性の検査を含めます。最初の2頂点の直接光と、接続先自体の発光は通常PTの寄与です。

提案は一次面の一様乱数と、再生先のBSDFでサンプルされた接続頂点の面積で定義します。乱数は両方向のシフトで同じ値を使います。接続で立体角PDFにヤコビアン `cos(接続先)/距離²` を掛け、再生区間のthroughputと再生先BSDFから寄与を計算します。シフトに失敗した方向のPDFはゼロです。光が得られなかったサンプルも、一次面の履歴判定に合格すれば提案として扱います。重みには既存のbalance MISを使います。

`--gi-view history` はシアンで選択された履歴、緑で再接続可能だった履歴、紫で再接続に使える候補がなかった履歴を表示します。赤は一次面の不一致、橙は履歴無効、黒は対象外の一次面です。通常の出力に切り替えると間接光を含む総照明を表示します。

```powershell
.\tests\RunPtHybrid.ps1 -Configuration Debug
.\tests\RunPtHybrid.ps1 -Configuration Release
```

鏡面と低粗さGGXのシーンで、通常PT、履歴なし、hybridのRGB平均を比較します。カメラの低速パンでは隣接フレーム間の画面上の輝度差を測ります。この指標には視点移動による画像の変化も含まれます。カメラカットでは履歴破棄と翌フレームの再開を検査します。同一GPU時間の比較は約1000 msで撮影し、通常PTの2048サンプルを参照にします。計測中は他の描画テストを並列実行せず、結果は `build/checks/pt-hybrid-<構成>/` に保存します。

RTX 3060 TiでDebug／Releaseともに、鏡面とGGXのRGB平均、履歴選択、カメラカットを確認しました。Releaseの鏡面シーンの平均輝度は通常PTが0.331191、hybridが0.331215でした。

| Releaseのモード | GPU時間 | サンプル数 | 輝度MSE |
| --- | ---: | ---: | ---: |
| 通常PT | 1016.0 ms | 98 | 0.003547 |
| hybrid | 1024.9 ms | 81 | 0.004245 |

低速パン時のフレーム差MSEは通常PTで0.01014、履歴なしのhybridで0.67091、履歴ありで0.66776でした。通常PTはカメラ移動に伴う蓄積リセット時に乱数系列を繰り返し、hybridはフレームごとに系列を進めます。履歴の効果を見る際は、乱数系列が揃うhybrid同士を比較してください。
