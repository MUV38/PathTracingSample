# パス再現と同一GPU時間の比較

```powershell
.\tests\RunPathReplay.ps1 -Configuration Debug
.\tests\RunPathReplay.ps1 -Configuration Release
```

`--path-replay` と `--path-replay-check` は同じピクセルの同じサンプルを、カメラジッター前の乱数シードから再実行します。レイ方向、ヒット種別・位置、BSDFと光源のPDF、Russian rouletteの継続確率を32ビットのダイジェストにまとめます。終了時の乱数状態とRGB放射輝度もビット単位で比較します。鏡面デルタイベントは確率質量として照合します。保存先はシェーダー内のローカル変数で、描画へは最初のトレースの寄与を使います。

同じシーン・フレーム内での決定性を確認する段階です。ダイジェストは衝突し得ます。フレームをまたぐパス保存、別ピクセルへの再接続、reservoirは後続の段階で扱います。

テストはPreview RoomのIBL・矩形光源、遮蔽物と発光メッシュのシーン、鏡面材質のPreview Roomを撮影します。画面右側35%のRGB値を通常PTと比較し、診断画像の一致色と複数レイの経路を確認します。

同じスクリプトで、遮蔽物シーンの通常PT・時間再利用・時間＋空間再利用を各約1000 GPU msで比較します。4096サンプルの通常PTを参照とし、蓄積した総照明の輝度MSEを測ります。GPU時間を比較するため構成と描画テストは順番に実行します。画像とサンプル数・実GPU時間・MSEのCSVは `build/checks/path-replay-<構成>/` に保存します。

RTX 3060 Tiで、Debug／Releaseともに3ケースすべての通常PTと再現画像が検査範囲内で一致しました。Releaseの同一時間比較では次の結果でした。

| モード | GPU時間 | サンプル数 | 輝度MSE |
| --- | ---: | ---: | ---: |
| 通常PT | 1006.8 ms | 204 | 0.000692 |
| 時間再利用 | 1008.7 ms | 160 | 0.000875 |
| 時間＋空間再利用 | 1013.1 ms | 86 | 0.001432 |
